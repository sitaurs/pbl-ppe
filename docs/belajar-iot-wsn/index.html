IoT vs WSN — Apa Bedanya?

WSN adalah fondasi dari banyak sistem IoT. Hover atau tap kartu untuk melihat detail.

IoT Internet of Things

Perangkat fisik yang terhubung internet, mampu sensing + actuation, sering bisa dikontrol jarak jauh.

  • FokusKonektivitas + kontrol
  • SkalaLokal sampai global
  • Data flowSensor → cloud → user
  • KonektivitasInternet end-to-end
Contoh project Dashboard Next.js + WhatsApp PIC + YOLOv8
VS

WSN Wireless Sensor Network

Kumpulan sensor node yang terdistribusi spasial dan terhubung wireless untuk memantau lingkungan.

  • FokusSensing & monitoring
  • SkalaLocal cluster
  • Data flowSensor → sink
  • KonektivitasWireless antar node
Contoh project ESP32 + MQ-135 per sektor → broker MQTT

Topologi WSN

Tiga topologi paling sering ditanya. Klik untuk melihat animasi data flow.

Dipakai project

Star

Semua node komunikasi langsung ke sink/gateway pusat.

  • Sederhana, mudah debug
  • Sink = single point of failure

Mesh

Setiap node bisa jadi router (multi-hop). Redundan dan tahan banting.

  • Jangkauan luas + redundan
  • Routing kompleks, boros energi

Tree / Cluster

Hierarki: cluster head agregasi data sebelum forward ke sink.

  • Skalabel untuk banyak node
  • Cluster head jadi titik kritis
