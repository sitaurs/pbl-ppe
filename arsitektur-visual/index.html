2. Dua Aplikasi Utama

Seluruh sistem berjalan dari dua proses di satu laptop, ditambah perangkat dan layanan pendukung.

1

Next.js

npm run start

Satu proses, port 3000. Frontend dan backend web menjadi satu:

  • Halaman antarmuka (React)
  • API /api/*
  • Login, sesi, RBAC
  • Database SQLite via Prisma
  • Audit log
2

Python YOLO

python ServiceAPDBackend.py

Satu proses. Kecerdasan deteksi dan komunikasi perangkat:

  • Tangkap frame kamera (RTSP / webcam)
  • Inferensi YOLOv8 helm dan rompi
  • Siaran frame via WebSocket port 8765
  • Notifikasi WhatsApp ke PIC
  • Alarm MQTT ke ESP32
  • Lapor pelanggaran ke Next.js
Mengapa hanya dua aplikasi?

Next.js adalah framework fullstack, sehingga frontend dan backend web berjalan dalam satu proses dengan satu port. Tidak perlu server terpisah untuk API.

4. Tugas Tiap Komponen

Next.js

Menangani seluruh antarmuka dan API web.

  • Render halaman: login, dashboard, monitor, pelanggaran, node, pengguna, peran, sektor, audit log
  • Verifikasi password Argon2id saat login
  • Buat sesi dan token CSRF
  • Periksa RBAC: 5 peran, 34 izin
  • Filter data per sektor untuk Supervisor dan PIC
  • Audit log otomatis
  • Uji koneksi RTSP dan MQTT
  • Pembatasan login dan 2FA TOTP

Python YOLO

Menangani deteksi AI dan komunikasi perangkat.

  • Tangkap frame dari RTSP atau webcam
  • Resize frame ke 720px untuk efisiensi
  • Inferensi YOLOv8 helm dan rompi
  • Inferensi deteksi orang (model terpisah)
  • Cross-check orang dengan APD via overlap kotak
  • Gambar penanda merah untuk pelanggaran
  • Siaran frame via WebSocket port 8765
  • Kirim WhatsApp ke PIC (cooldown 120 detik)
  • Publikasi alarm MQTT terenkripsi AES-128
  • Lapor pelanggaran ke Next.js via service token

SQLite

Penyimpanan data permanen.

  • Tabel: User, Role, Permission, Session, Sector, Node, Violation, Setting, AuditLog
  • Diakses via Prisma dari Next.js
  • Mode WAL untuk akses bersamaan
  • Lokasi: web-dashboard/data/safeguard.db
  • Python mengakses lewat API, bukan langsung

ESP32

Mikrokontroler alarm fisik.

  • Berlangganan MQTT topik APD_Violation
  • Dekripsi pesan AES-128
  • Memutar MP3 alarm melalui DAC ke speaker
  • LED indikator status koneksi dan alarm

HiveMQ (MQTT)

Perantara pesan Python ke ESP32.

  • Port 8883 dengan TLS
  • Topik APD_Violation
  • Python publikasi, ESP32 berlangganan
  • Alternatif: Mosquitto lokal port 1883

Cloudflare Tunnel

Akses jarak jauh aman.

  • Daemon cloudflared sebagai Windows service
  • Meneruskan domain ke localhost:3000
  • TLS otomatis, tanpa membuka port router
  • Loopback tetap berfungsi saat tunnel mati

6. Cara Menjalankan

Urutan penting: Next.js lebih dulu, baru Python.

1

Terminal 1 — Next.js

cd web-dashboard
npm run start

Tunggu hingga muncul "Ready". Akses di http://localhost:3000.

2

Terminal 2 — Python

python ServiceAPDBackend.py

Tunggu hingga model dimuat dan WebSocket aktif pada port 8765.

3

Opsional — Cloudflare Tunnel

cloudflared tunnel run

Hanya diperlukan untuk akses jarak jauh.

7. Pertanyaan Umum

Mengapa Python memakai service token, bukan login biasa?

Python adalah proses mesin, bukan pengguna manusia. Login sesi dirancang untuk manusia dengan cookie dan CSRF. Service token adalah metode standar autentikasi mesin-ke-mesin yang lebih sederhana dan tanpa kedaluwarsa sesi.

Jika Python berhenti, apakah Next.js tetap jalan?

Ya. Seluruh halaman web tetap berfungsi. Hanya live monitor yang kosong karena sumber frame dari Python berhenti.

Jika Next.js berhenti, apakah deteksi tetap jalan?

Deteksi YOLO tetap berjalan karena Python independen. Namun Python tidak dapat melaporkan pelanggaran baru ke database hingga Next.js kembali aktif.

Mengapa Python tidak mengakses SQLite langsung?

Agar ada satu sumber kebenaran. Semua perubahan data melewati Next.js sehingga tercatat di audit log, tervalidasi, dan tidak terjadi konflik tulis bersamaan.

Apakah ESP32 perlu internet?

Perlu jika memakai HiveMQ Cloud. Jika memakai broker Mosquitto lokal, ESP32 cukup terhubung ke WiFi yang sama dengan laptop.
